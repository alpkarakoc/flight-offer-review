# Flight Offer Review

A full-stack application for searching, filtering, sorting, and validating synthetic flight offers.

## Tech Stack
- **Client**: Angular 21 (Zoneless), TypeScript, Vitest
- **Server**: Spring Boot 3, Java 17, Maven

## Status
- **R1-R5 Completed**: 60+ unit and integration tests covering UI interactions, error handling, strict synthetic data validation, and real HTTP contract enforcement.
